## Description
A music streaming platform that enables users to listen to and explore songs, albums, and playlists.
The initial dataset included around 6,000 songs and 3,000 artists manually crawling from Spotify. Integrated a
simple collaborative filtering recommendation system to suggest songs based on user behavior and preferences.
## Techstack
Backend: Spring Boot, FastAPI, Apache Kafka, Kubernetes
Frontend: Angular
